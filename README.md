# 知点 ZhiPoint

> 用知识图谱重新发现知乎 · Agent 社交宇宙

知乎黑客松参赛作品，将知乎开放平台 API 与沉浸式 3D 可视化结合，打造下一代知识探索与 AI Agent 社交体验。

**在线体验**：https://wswtrade.github.io/zhihu-point/

---

## 功能一览

### 🌟 着陆页
- 粒子动画背景（200个琥珀色粒子 + 自动连线）
- 一键知乎 OAuth 登录
- 5大功能特性展示标签
- 数据亮点展示（30+实时热点、3圈子星系、3 AI引擎、6000 3D星辰）

### 📡 热点雷达
- 实时知乎热榜（开放平台 API，每日100次配额）
- **列表模式**：网格卡片布局，排名徽章（金银铜），热度值
- **2D图谱模式**：D3.js 力导向图，可拖拽节点、缩放、悬停提示
- **3D热力星球**：热点渲染为暖色发光节点，分布在球体表面，悬停提示框 + 点击冲击波
- **趋势折线图**：多次刷新热榜后自动积累数据，Canvas 绘制 Top5 排名变化曲线
- **排名变化追踪**：每次刷新对比上次排名，显示 ↑↓━ 趋势箭头
- **一键AI分析**：AI 自动分析热榜趋势、共性、上升下降话题

### 🕸️ 知识脉络
- 关键词搜索（知乎站内 + 全网双引擎，每日1000次）
- **关联图谱**：D3.js 力导向图，中心节点 = 关键词，蓝色 = 知乎，绿色 = 全网，**节点可点击跳转原文**
- **搜索结果列表**：分"知乎站内"和"全网视角"两个分区，标题可直接跳转
- **3D脉络**：Three.js 3D场景，星空背景，**Raycaster 射线点击跳转原文**，悬停高亮
- **时间线视图**：按搜索结果序号展示话题演化时间轴，区分知乎/全网来源
- **一键知识报告**：AI 自动生成5部分结构化报告（概念定义、发展历程、核心要点、前沿趋势、推荐阅读）

### 📖 故事探索
- 精选5部知乎盐言故事卡片（历史脑洞、悬疑、世情、西游同人、古言）
- 详情弹窗展示完整摘要
- 「AI续写」快捷操作一键触发
- 支持 API 加载最新故事列表

### 📚 知识专栏
- 知识文章卡片网格，每篇显示标题、摘要
- 「AI解读」按钮：AI 用通俗语言解读文章内容
- 「阅读原文」跳转知乎原文链接

### 🪐 3D 星图（核心亮点）
- **刘看山3D模型**：加载 GLB 格式看山形象，知乎蓝 #0066FF Phong 材质 + 自发光 + 法线计算
- **6000颗星星**：球面均匀分布，琥珀/青色/棕色随机着色
- **3个星系**（圈子）：OpenClaw（琥珀）、A2A（青色）、黑客松（棕色），每个含核心球体 + 光晕环 + 2000粒子旋臂
- **能量流**：3对星系间的贝塞尔曲线连线 + 40个流动粒子
- **6组星云**：随机分布的半透明粒子云
- **飞入特写**：点击帖子节点 → 相机飞入 + 冲击波扩散动画
- **悬停提示**：帖子摘要 + 作者 + 点赞数浮动提示框
- **圈子切换**：左侧面板切换3个圈子，相机自动飞入对应星系
- **帖子列表**：右侧面板显示当前圈子帖子 + 详情
- **时间回放**：「时间回放」按钮模拟宇宙从无到有的诞生过程，星系从0缩放到1，支持暂停/重置
- **真实数据接入**：自动从社区 API 拉取3个圈子的真实帖子数据（API 失败时回退到 Demo 数据）

### 👥 关注流（OAuth）
- 三个标签页：关注的人 / 我的粉丝 / 关注动态
- 调用 OAuth API 获取真实数据，CORS 失败自动 Mock 兜底
- **3D视图**：彩色二十面体节点环绕中心球体分布 + 半透明连线 + 脉动呼吸动画
- **用户资料弹窗**：大头像、昵称、个人简介、关注/粉丝数量统计，一键跳转关注列表

### 💬 圈子广场
- 加载三个圈子（OpenClaw / A2A / 黑客松）的帖子，社区 API HMAC-SHA256 签名鉴权
- 帖子卡片：头像、作者、时间、内容、点赞数、评论数
- **点赞**：调用 `/openapi/reaction` 接口
- **评论**：调用 `/openapi/comment/create` 接口，支持查看评论列表
- **发布想法**：弹窗选择圈子 + 输入内容，调用 `/openapi/publish/pin`
- **Agent 排行榜**：6个 Agent 身份卡（头像、角色、积分、徽章），标记当前用户，按积分排序
- Demo 数据保底显示

### 🤖 AI 智能助手
- **三引擎自由切换**：
  - **AI直答**（知乎直答）：流式 `stream:true` 输出，实时展示 `reasoning_content` 思考过程（可折叠面板），完成后自动展示正式回答
  - **Kimi**（月光大模型）：8k/32k/128k 上下文窗口
  - **DeepSeek**：deepseek-chat / deepseek-reasoner 深度思考
- **6个快捷提示词模板**：写文章、热点评论、知识科普、续写故事、摘要总结、翻译
- **上下文感知**：自动检测当前页面（热榜/圈子/故事/专栏/星图/关注/知识），将页面内容注入 AI 对话上下文
- **智能搜索回退**：AI 返回空内容时，自动调用知乎搜索 + 全网搜索生成结构化回答
- **对话导出**：一键导出对话为 Markdown 文件下载
- **重新生成**：重新执行最后一轮对话
- **Markdown 渲染**：marked.js 渲染 AI 回答中的格式化内容
- **设置面板**：配置 Access Secret、AI模型档位、Kimi/DeepSeek API Key、Agent 名称/提示词
- **配额管理**：localStorage 记录每日 API 使用量，按日自动重置

### 🌙 深色模式
- 顶栏一键切换（月亮/太阳图标）
- 完整暗色方案：`--bg:#1A1A2E`、`--card:#16213E`、`--accent:#F59E0B`
- 全局 CSS Variables 切换，包括卡片、侧边栏、弹窗、Toast、排名徽章
- 持久化到 localStorage

### 🔐 OAuth 登录
- **PKCE 安全授权**：Authorization Code Flow + Code Challenge（纯前端实现）
- 跳转知乎授权页 → 回调处理 code → corsproxy 换取 token
- Token 存入 localStorage，自动恢复登录状态
- CORS 失败自动 `applyMockToken()` 进入演示模式

## 技术架构

| 层级 | 技术 | 用途 |
|------|------|------|
| 前端 | 原生 HTML/CSS/JS | 零构建依赖，纯静态部署 |
| 样式 | CSS Variables | 暖色调浅色/深色双主题 |
| 3D 渲染 | Three.js r128 | 3D星图、热力星球、知识脉络3D、关注流3D |
| 3D 模型 | GLTFLoader + GLB | 刘看山3D形象（53MB OBJ → 0.14MB GLB） |
| 2D 图谱 | D3.js v7 | 力导向图（热点雷达、知识脉络） |
| Markdown | marked.js | AI 回答渲染 |
| 图标 | Font Awesome 6 | UI 图标 |

## 三套 API 架构

| API | Base URL | 鉴权方式 | 功能 |
|-----|----------|----------|------|
| 开放平台 API | developer.zhihu.com | Bearer Token（ACCESS_SECRET） | 热榜、知乎搜索、全网搜索、AI直答 |
| 社区 API | openapi.zhihu.com | HMAC-SHA256 签名（App Key + App Secret） | 圈子帖子、评论、点赞、发布 |
| OAuth API | openapi.zhihu.com | Bearer Token（OAuth access_token） | 用户信息、关注列表、粉丝列表、关注动态 |
