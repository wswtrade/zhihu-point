# 知点 ZhiPoint

> 用知识图谱重新发现知乎 · Agent 社交宇宙

知乎黑客松参赛作品，将知乎开放平台 API 与沉浸式 3D 可视化结合，打造下一代知识探索与 AI Agent 社交体验。

**在线体验**：https://wswtrade.github.io/zhihu-point/

## 已完成功能

### 🌟 着陆页
- 粒子动画背景（200个琥珀色粒子 + 自动连线）
- 一键知乎 OAuth 登录
- 功能特性展示

### 📡 热点雷达
- 实时知乎热榜（开放平台 API）
- 列表/2D图谱/3D图谱 三种视图
- 热度排名徽章、卡片网格布局

### 🕸️ 知识脉络
- 关键词搜索（知乎站内 + 全网双引擎）
- **2D关联图谱**：节点可点击跳转原文链接，悬停显示摘要
- **3D脉络**：Raycaster 射线点击跳转，悬停高亮
- 搜索结果列表（分区展示）

### 📖 故事探索
- 精选知乎盐言故事卡片
- 详情弹窗 + AI续写快捷操作

### 📚 知识专栏
- 知识文章卡片网格
- AI解读按钮 + 原文链接

### 🪐 3D 星图（核心亮点）
- **刘看山3D模型**（知乎蓝 #0066FF 材质 + 自发光）
- 6000颗星星 + 3个圈子星系（旋臂粒子）
- 星系间能量流 + 星云
- 点击帖子节点飞入特写 + 冲击波动画
- 圈子切换面板 + 帖子列表

### 👥 关注流（OAuth）
- 关注/粉丝/动态 三标签页
- **3D视图**：彩色二十面体节点 + 连线 + 脉动动画
- 用户资料弹窗

### 💬 圈子广场
- 三个圈子帖子加载（社区 API HMAC 签名）
- 点赞、评论、发布想法
- Demo 数据保底

### 🤖 AI 智能助手
- **三引擎**：知乎直答（流式输出）+ Kimi + DeepSeek
- **流式思考过程**：reasoning_content 折叠面板实时展示
- **6个快捷提示词**：写文章、热点评论、知识科普、续写故事、摘要总结、翻译
- **上下文感知**：自动注入当前页面内容到对话
- **智能回退**：AI 返回空时自动搜索补全
- 设置面板配置各模型 API Key

### 🔐 OAuth 登录
- PKCE 安全授权（纯前端）
- 自动恢复登录状态
- CORS 失败自动 Mock 演示模式

## 技术栈

| 技术 | 用途 |
|------|------|
| 原生 HTML/CSS/JS | 零构建，纯静态 |
| Three.js r128 | 3D 星图、知识脉络、关注流 |
| D3.js v7 | 力导向图谱 |
| marked.js | Markdown 渲染 |
| CSS Variables | 暖色调主题 |

## 三套 API

| API | 鉴权 | 功能 |
|-----|------|------|
| 开放平台 API | Bearer Token | 热榜、搜索、AI直答 |
| 社区 API | HMAC-SHA256 | 圈子帖子、评论、点赞 |
| OAuth API | Bearer Token | 用户信息、关注、粉丝 |
